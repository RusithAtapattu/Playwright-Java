# Playwright with Java Automation

This repository demonstrates **web automation using Playwright with Java**. It covers setting up the environment, creating a Maven project, writing and executing tests, using TestNG, implementing the Page Object Model (POM), working with locators, generating reports, and managing the project with Git.

---

## 📌 Topics Covered

### Getting Started
- Setup Java
- Setup Eclipse IDE
- Setup Maven
- Create Maven Project
- Add Playwright Dependency
- Write and run the first Playwright test

### Framework Development
- Playwright Framework Structure
- TestNG Integration
- Recording Playwright Tests

### Test Design
- Page Object Model (POM)
- Locators in Playwright

### Reporting
- Test Reports Generation

### Tools & Utilities
- Running tests using CMD
- Version control using Git

## ⚙️ Setup Instructions

### 1️⃣ Clone the repository
```bash
git clone https://github.com/your-username/playwright-java-automation.git
cd playwright-java-automation
```

### 2️⃣ Install dependencies
Make sure **Java and Maven** are installed.

```bash
mvn clean install
```

---

## ▶️ Running Tests

Run tests using Maven:

```bash
mvn test
```

You can also run tests directly from **Eclipse IDE using TestNG**.
